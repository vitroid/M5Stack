# LaserBlinker（リカンベント）— PLAN2

リカンベント用のウインカー／ブレーキライト。前部をマスタ、後部を灯火スレーブとする。開発は PlatformIO。

---

## 構成概要

```text
[USB-C Battery]
    → PDトリガー → 12V ─┬→ メカSW → 前照灯
                        ├→ Core制御 → N-MOSFET → 前ウインカー(12V L/R)
                        └→ Buck → 5V → Core + Proto13.2 (+ GPSは ver2)
                                        │
              GX12-4 (5V, GND, RS-485 A/B) │ ～2m ツイスト＋太電源
                                        ▼
                              [後部: Atom Lite + MAX485]
                                        → WS2812 テープ（後ウインカー＋テール）
                                        → （ver2）レーザー L/R
```

---

## 電源

1. USB-C モバイルバッテリ → PDトリガーで **12V**
2. 同じ 12V から降圧（buck）で **5V**（前後 MCU・WS2812・RS-485）
3. 前照灯・前ウインカーは **12V のまま**（メカSW／MOSFET）

幹線の 5V/GND は信号より **太芯**。電圧降下が厳しい場合は、幹線を 12V＋GND＋A/B にし、**後部で 12V→5V 降圧**する案も可（部品は増えるが長距離給電に有利）。

---

## 前部（マスタ）

- **MCU**: M5Stack Core ＋ **Module13.2 Proto（M032）**
- **GPS**: M5Stack 用モジュール入手済み。**実装は ver2**（今はピンを後部通信に優先）
- **入力**
  - ブレーキレバー（左右 OR）→ GPIO
  - 既設ウインカースイッチ L/R → GPIO
- **出力**
  - 前照灯: **メカニカルスイッチ**で 12V（MCU 非経由）
  - 前ウインカー: Core が点滅タイミングを生成 → **N-MOSFET** で 12V 負荷を低側スイッチ
- **幹線**: Proto 上に MAX485 を載せ、GX12-4 へ出す

### Proto13.2 の使い方

見た目は穴あき基板だがブレッドボードではない。**はんだ付け＋同梱 HT3.96 ネジ端子**で電線を固定する。Core とは M-Bus スタックで接続。

### GPS とのピン（ver2 向けメモ）

GPS は UART2（G16/G17＝Port C）が定番。後部リンクは **別 UART**（例: Port A 相当 G32/G33 → MAX485）に分ける。

---

## 前後幹線

| 項目 | 内容 |
| --- | --- |
| コネクタ | **GX12-4**（自前割当・ラベル必須） |
| ケーブル | ～2m。A/B はツイストペア、5V/GND は太線 |
| 物理層 | **RS-485**（前後に MAX485 等）。論理は UART |
| ボーレート | まず **9600**、安定後に上げる |

### GX12-4 ピン割当（本プロジェクト定義）

| Pin | 信号 |
| --- | --- |
| 1 | 5V |
| 2 | GND |
| 3 | RS-485 A |
| 4 | RS-485 B |

※ GX12 に業界標準ピンはない。他用途ケーブルとの誤挿に注意。

### プロトコル（案）

- Core → 後部: `TURN=L\|R\|0`, `BRAKE=0\|1` 等（1行テキスト＋checksum）
- 後部 → Core: `ACK` / `FAULT`、ハートビート
- **通信断タイムアウトで後部は全消灯**（フェイルセーフ）
- 点滅タイミングは **Core がマスタ**（前 FET と後部テープを同期）

## 後部（スレーブ）

### 採用: M5Atom Lite（既定）

StampS3 より **結線しやすい**。はんだ必須ではない。

| 接続 | 方法 |
| --- | --- |
| 幹線 UART（MAX485 の DI/RO） | **Grove（G26/G32）** または底板ピンへ Dupont／短い線 |
| WS2812 DATA | 底板 GPIO（例: G19 / G22 / G23 等）へ Dupont またははんだ |
| 5V / GND | GX12 → MAX485／Atom の 5V・GND（共通） |
| MAX485 モジュール | ネジ端子付きモジュールを短い線で Atom／Grove に接続 |

Atom Lite 底板はピンヘッダ差込向き。振動対策としては:

1. **小さな穴あきユニバーサル基板**に Atom Lite（ピンヘッダ）＋ MAX485 ＋ ネジ端子／GX12 をまとめる（推奨）
2. または 3D プリント筐体に Atom・MAX485・GX12 を固定し、内部は短線

**StampS3** はピンが出ているだけでコネクタがないため、**ピンヘッダのはんだ付け＋キャリア基板**がほぼ必須。小型化したいときの選択肢。本プランの既定は Atom Lite。

### 後部の役割

- RS-485 経由で TURN／BRAKE を受信
- **WS2812 テープ**で後ウインカー L/R ＋テール（尾灯低輝度／ブレーキ時ハイ）を描画
- ACK／ハートビート返信
- **レーザーウインカーは ver2**（FET×2 を追加する想定）

### 放熱（WS2812）

アルミチャンネルに密着。常時は低 PWM、ブレーキ時のみ高輝度。

## 試作（bench / ver0）— ソフトウェア確認

**目的**: 本番配線の前に、机上でロジックと通信を確認する。**すべて 5V 駆動**。前後 MCU は **ブレッドボード**上。

### 試作構成

```text
[5V USB電源] ─┬→ M5Stack Core（ブレッドボード）
              └→ Atom Lite（ブレッドボード）
                    │
         短い Dupont または MAX485×2（数cm〜数十cm）
                    │
              WS2812 テープ（短い試作用）
```

| 本番 | 試作での代用 |
| --- | --- |
| 12V＋PD＋buck | **5V USB 給電**（バッテリの5Vポート or USBケーブル） |
| Proto13.2＋ネジ端子 | **ブレッドボード** |
| GX12-4＋2m幹線 | **短いジャンパ**（RS-485 も机上なら数cmで可） |
| 前ウインカー 12V＋MOSFET | **LED＋抵抗**（GPIO 直 or 小信号） |
| ブレーキレバーセンサ | **タクトSW**（左右 or OR 1本） |
| 既設ウインカーSW | **タクトSW L/R**（既設SWを使っても可） |

### 確認項目（受け入れテスト）

1. **ブレーキ SW ON** → 後部 WS2812 が **赤**（テール全体 or 定義した範囲）
2. **ブレーキ SW OFF** → 尾灯相当の **低輝度** に戻る（または消灯）
3. **ウインカー L** → 前部 **黄色 LED 点滅** ＋ 後部テープ **左端が黄色点滅**
4. **ウインカー R** → 前部 LED ＋ 後部 **右端** 黄色点滅
5. **キャンセル** → 前後とも消灯／アイドル
6. **通信断**（ケーブル抜く等）→ 後部テープ **全消灯**（フェイルセーフ）
7. （任意）Core 側点滅位相と後部が **同期**している

### 試作の配線メモ

- **通信**: 最初は MAX485 なしの **UART 直結**（Core TX↔Atom RX クロス）でも可。動いたら MAX485 を挟んで同じテストを繰り返す
- **Core UART**: Serial2 RX=16 TX=17 または Port A 相当
- **Atom UART**: Serial1 RX=32 TX=26（Grove 相当）
- **WS2812 DATA**: Atom の空き GPIO 1本（例: G19）。FastLED 等
- **前部 LED**: 330Ω 前後＋ GPIO（左右で別ピン）。Core Btn は未使用でも可
- **入力**: `INPUT_PULLUP`、SW 押下で GND

### 試作で不要（ver1 以降）

PDトリガー、12V→5V buck、GX12-4、2m幹線、Proto13.2、MOSFET、前照灯メカSW、アルミチャンネル（短テープなら省略可）
