# 前後ユニット PCB 配置方針（引き継ぎ）

2026-11-14 時点の端子配置・向き・動かさない条件。回路定数とピン表の正本は `docs/front-pcb-design.md` と `docs/rear-pcb-design.md`。座標の正本は各 `*.kicad_pcb` と `scripts/build_pcb.py`。この文書とスクリプトが食い違うときは、スクリプトと基板ファイルを見る。

## いきさつ

いまの KiCad は、動いている試作を JLCPCB の一枚基板にまとめ、そのうえで拡張したものである。ファームウェアは試作の MCU 向けのまま残している。基板のピンに合わせて書き換える作業は、まだ始めていない。

三層ある。

1. **初期メモ** — `PLAN.md` と `PLAN2.md`。前部は M5Stack Core ＋ Proto13.2、後部は M5Atom Lite。幹線は GX12-4 で 5V を送る案。レーザーと GPS は ver2。机上確認は 5V のブレッドボード。このメモの MCU と幹線電圧は、その後の実機と違う。
2. **実装済みの試作** — 市販モジュールの組み合わせで組み、ESP32-C3 SuperMini 用のコードを書いて載せた。正本は `src/front/`、`src/rear/`、`src/common/protocol.h`、`platformio.ini` の `esp32-c3-supermini-front` / `esp32-c3-supermini-rear`。結線は `docs/front-circuit.md` と `docs/rear-circuit.md`。
3. **今回の一体基板** — `hardware/front-core/` と `hardware/rear-core/`。上の試作の機能を SMD とネジ端子ごと一枚に載せ、JLCPCB へフル実装で出す。設計書は `docs/front-pcb-design.md` と `docs/rear-pcb-design.md`。

試作の中身は次のとおり。

- 前部: USB-C バッテリ → 外付け PD トリガーで 12V。前照灯はその 12V をメカスイッチで断続し、MCU を通さない。前ウインカーは N-MOSFET の低側スイッチ。5V は外付け DC-DC。MCU は ESP32-C3 SuperMini。トランシーバは MAX485 モジュールで、DE/RE を VCC に固定して送りっぱなし。
- 後部: GX12 の 12V を外付け DC-DC で 5V にし、ESP32-C3 SuperMini と WS2812 テープと MAX485 を駆動する。DE/RE は GND 固定で受けっぱなし。`PLAN.md` の「幹線は 5V」はこの実機で 12V に変わっている。
- 幹線: GX12-4。1=12V、2=GND、3=A、4=B。約 2 m。
- 端子: 電力は 5.08 mm（`P2` 左ウインカ、`P3` 右ウインカ、`P4` 前照灯、`P5` 幹線の 12V/GND）。信号は 2.54 mm。ウインカ SW は `S1` の 3P で左右を `G0` / `G1` へ。ブレーキ左右は基板上で並列にして `G3` 一つ。`S5` は予備。状態 LED は `S4`（GND / DATA / 5V）の WS2812 が 2 灯。
- 回線: 9600 bps の 1 行テキスト。前部は 100 ms 周期で `S,turn=L|R|B|0,brake=0|1` を送る（`src/front/main.cpp`）。後部はこれを読んでテープを灯し、`ACK` を書く（`src/rear/main.cpp`）。試作の DE は固定なので、この `ACK` はバスに出ていない。後部は `LinkSerial.setRxInvert(true)` で MAX485 モジュールの極性を吸収している。通信が 500 ms 途切れるとテープは消灯する。

一体基板で足したもの、変えたもの。

| 試作 | 一体基板 |

## 共通

- 基板相対座標は X が右、Y が下。スクリプトの `V(x, y)` は絶対座標に原点 `(100, 80)` を足す。`y = 0` が上辺、`y = H` が下辺。
- ケースを薄くするため、線の出るコネクタは横出し。開口は一方向に集める。
- Espressif のアンテナ指針は、モジュールアンテナをホスト基板の外へ出すこと。出せないときはアンテナ下と横の銅箔を切り、周囲 15 mm を銅箔禁止にする。両基板とも「外へ出す」を採っている。前部は左へ約 5 mm、後部は上辺。15 mm 全周はケース寸法に合わないので、はみ出し＋アンテナ直下のキープアウトで妥協している。
- 3D プレビューは Edge.Cuts で切れる。はみ出したアンテナは `3d-top.png` / `3d-iso.png` に出ない。向きの確認は pcbnew 上のアンテナ端座標で行う。レンダラには `--define-var KICAD10_3DMODEL_DIR` を KiCad の `3dmodels` へ向ける。
- プレビューでランドだけの部品は未実装ではない。この KiCad に STEP が無い。前部で欠けるのはネジ端子台、USB-C、RJ45、ESP32、ブザー、`L1`、`F1`、タクトスイッチ。モデルを持たないのはテストポイントとソルダージャンパ。抵抗・チップコンデンサ・ダイオード・IC・電解コンデンサ・横出し JST は立体が出る。
- SMD は表面だけ。裏面は配線と GND。
- 直列抵抗とシャントコンデンサはトポロジを変えない、という整理までで止まっている。2 本足を外したスケルトン回路図は作らない。電源の 2 本足（`L1`、`F1`、`D1`、OR ダイオード、ヒューズ）とランプ FET は残す。回路図は消さない。
- Freerouting は部品を動かさない。手配線を残すときは DSN の `(type route)` を `(type protect)` に書き換えてから渡す。`-mt` は `1`。`-mt 4` はクリアランス違反を作る。Java はサンドボックスでは動かない。配置だけの保存は、配線済みの基板ファイルを上書きする。未接続数と DRC が出るまで配線済みと言わない。

## 前部（`hardware/front-core/`）

縦長、ハンドル縦棒。設計対象は **36 × 120 mm**（`FRONT_BOARD_SIZE=36x120`）。候補サイズは `(36,120)`, `(35,115)`, `(38,125)`, `(40,130)`。取付穴は置かない（`H1`〜`H4` は回路図に残し、PCB には出さない）。

生成は `scripts/generate_front_kicad.py` のあと `scripts/build_pcb.py`。KiCad 付属 Python で実行する。

### エッジの割り当て

上辺にコネクタは置かない（防水。状態表示はケース上の tape LED）。

| 辺 | 上から / 左から | 向き | 線の出る方向 |
| --- | --- | --- | --- |
| 左 | `P2`, `S1`, `S2`, `P4` | rot 90 | 左 |
| 右 | `P3`, `S5`, `S3`, `S4` | rot 270 | 右 |
| 下 | `J2` USB_PWR、その右に `J1` RJ45 | 下向き | 下 |
| 左中段 | `J3` USB_DBG | パッド平均 X が正になる回転（実測 −90） | 左 |
| 右中段 | `J4` Navi | rot 90 | 右 |

左列はウインカと前照灯、右列は右ウインカ・ブレーキ・状態 LED。`S2` は左列、`S3` と `S4` は右列。全部を上辺へ集めない。

端子はすべてネジ式の横出し。種類を変えない。

| 記号 | 型番 | フットプリント | LCSC | 役割 |
| --- | --- | --- | --- | --- |
| `P2` `P3` `P4` | `KF350-3.5-2P` | `TerminalBlock_4Ucon:TerminalBlock_4Ucon_1x02_P3.50mm_Horizontal` | `C474892` | 12 V ランプ（左ウインカ / 右ウインカ / 前照灯） |
| `S1` `S2` `S3` `S5` | `XY308-2.54-2P` | `TerminalBlock:TerminalBlock_Xinya_XY308-2.54-2P_1x02_P2.54mm_Horizontal` | `C557685` | ウインカ SW とブレーキ SW |
| `S4` | `XY308-2.54-3P` | `TerminalBlock_Xinya_XY308-2.54-3P_1x03_P2.54mm_Horizontal` | `C557686` | WS2812。1=`GND`、2=`LED_DATA_5V`、3=`+5V` |
| `J4` | `S4B-PH-K(LF)(SN)` | `Connector_JST:JST_PH_S4B-PH-K_1x04_P2.00mm_Horizontal` | `C265452` | M5Stack Navi。Grove 2.0 mm 互換の横出し |

`J4` を `HY2.0-4P`（LCSC `C160404`、縦挿し）へ戻さない。ローカル +Y がシュラウド。rot 90 で +Y が基板の +X になり、ケーブルは右へ出る。ピンは 1=黄=`NAVI_RX`（GPIO12）、2=白=`NAVI_TX`（GPIO13）、3=赤=`+5V_NAVI`、4=黒=`GND`。

`J3` は左辺。USB の D+/D− と ESD（`U7`）を短くするため。`J2` は下辺のまま RJ45 と並べる。二つの USB-C はシルクで分ける。`USB_PWR` は `12V PD IN (BATTERY)`、`USB_DBG` は `MCU USB (PC)`。

### アンテナと MCU

`U4` は `ESP32-S3-MINI-1-N8`。フットプリント名は `RF_Module:ESP32-S2-MINI-1`。KiCad の Y 下向きで、rot 0 はアンテナが上、**rot 90 が左**、rot 180 が下、rot 270 が右。

使う姿勢は `u4_rot = 90`、`u4_cx = 5.5`。先端（ローカル y = −10.6）は `x ≈ −5.1`。パッド（ローカル y ≥ −4.45）は基板上に残る。衝突でずらすときは `u4_cy` を増やす（下へ）。右へ動かすとアンテナが基板に戻る。

衝突判定の箱は本体 `[0.6, cy−8.5, cx+11, cy+8.5]`。フルコートヤードはアンテナキープアウトを含むので、隣の部品と重なったように見える。`J3` と `U4` の DRC「コートヤード重なり」はこのキープアウト。本体は縦に約 5.5 mm 離れている。このフラグを消すために `J3` や `U4` を動かさない。GND ベタの穴とステッチビア除外も、同じキープアウト箱を使う。

### 電源の流れと降圧の置き方

下端 `USB_PWR` → `F1` → `D1` → `U0` CH224K で 12 V → `U1` / `L1` で 5 V → `C7` / `C5` / `C6` → MCU。ランプの 12 V は降圧を通さない。下の 12 V バスから `P2` / `P3` / `P4` へ行く。Navi の 5 V と WS2812 は `+5V` から取る。

`F1` は `J2` の VBUS 列の上。`D1` はその真上（右端 ≤ 13.5、`F1` の中心に合わせる）。`U0` はその上（右端 13.7、間隔 0.6 mm）。三者は RJ45 コートヤードの左（x < 13.8）に縦積みする。`F1` と `D1` を横並びに戻さない。

`U0` の CFG1（pin 9）は 24 kΩ で 12 V を要求する。56 kΩ は 15 V 要求になるので変えない。`R23` はそのピンの隣に置き、1 本の短いパターンでつなぐ。

Buck は MCU 本体の下、`U0` の上。`U1` は **180°**。rot 0 だとスイッチピン（pin 2）がコイルと反対側を向き、入力コンデンサとのあいだに 0.20 mm の通路しか残らない。180° では pin 2 が `L1` pin 1 と同じ高さになり、約 2.4 mm の直線でつながる。並びは `U1` | 0.4 mm | `L1` | 0.4 mm | `C7`。`C5` と `C6`（22 µF）は `L1` の出力パッド側、間隔 0.35 mm。`C7`（220 µF / 10 V、`CP_Elec_6.3x7.7`、`C128268`）は降圧のバルク。tape LED 用ではない。tape LED の 22 µF は `S4` 側の `C17`。`BZ1` は右辺 Grove の直下。

`Q1` は `P2` の内側、`Q2` は `P3` の内側、`U6` は `S4` の内側。`D4` / `D5` / `R14` は端子コートヤードから約 0.2 mm 以上離す（2026-11-14 に各 0.4 mm ずらして解消済み）。

### 配線で守ること

2026-11-14 の 36 × 120 は、ショート 0、クリアランス 0、未接続 3。残りは移設した `U0` まわりの `R21`（`VBUS_PD` → pin 8）、`R22`（`VBUS_PD` → pin 1）、`J3` の CC1 → `R3`。コートヤード重なりの残りは `J3` と `U4` のキープアウトだけ。USB シェルのサーマル不完全が 2 件ある。

- `J2` の二つの VBUS 列（A4/B9 と A9/B4）は、ピン列の基板端側・裏面で結ぶ。CC、D+/D−、GND を横切る直線を引かない。
- `J2` の CC1（A5）は裏面で `U0` pin 7 へ上げる。
- `+12V` の背骨は左のネジ端子の内側、B.Cu、約 0.8 mm。`D1` の `+12V` から `P2` と `P4` まで。`U1` pin 3 への入りは 0.4〜0.5 mm に細め、スイッチピンと反対側から入る。ピンピッチ約 0.94 mm の列へ 1.0 mm を通さない。
- `POWER_TRACK_WIDTH_MM["+3V3"]` は 0.25 mm。太い幅がクリアランスを満たすセグメントだけ太くする。USB と SW の細い首を床幅（0.8〜1.0 mm）へ戻すとショートする。
- `try_bridge_short_rats` は呼ばない。短いラッツを無検査で結ぶとショートを塗る。
- GND ステッチビアは、アンテナキープアウトと、GND 以外の銅から `0.3 + 半幅 + 0.2` mm 以内を避ける。
- USB-C ピン列の 0.15 mm はコネクタのピッチと NPTH アンカー。隣の部品を動かしても開かない。この隙間を広げるために `J2` / `J3` を動かさない。

ファームの `src/front/pins.h` はまだ ESP32-C3 SuperMini。PCB と `docs/front-pcb-design.md` §3 が ESP32-S3 の正。頼まれない限り `pins.h` を書き換えない。

## 後部（`hardware/rear-core/`）

横長、座席もたれ。正本以外の `hardware/rear-core-claude/` は参照にも発注にも使わない。

コネクタは下辺、左からこの順。変えない。

| 記号 | 部品 | ピン |
| --- | --- | --- |
| `J2` | WS2812、`S3B-XH-A` 横出し（`C157927`） | 1=`+5V`、2=`LED_DATA_5V`、3=`GND` |
| `J4` | USB Type-C `TYPE-C-31-M-12`（書込用の 1 口） | CC1/CC2 は各 5.1 kΩ → GND |
| `J1` | トランス無し RJ45 | 前部 `J1` と CAT5 ストレート。1=`A`、2=`B`、4,5=`+12V`、7,8=`GND`、3,6=`NC` |
| `J3` | 拡張、`S4B-XH-A` 横出し（`C157928`） | 1=`+12V`、2=`+5V`、3=`GND`、4=`EXP_CMD`（GPIO4、3.3 V） |

12 V は RJ45 幹線から入る。PD トリガーは前部だけ。レーザー駆動 MOSFET は持たない。`J3` は電源と 3.3 V コマンドだけ渡す。

ゾーンは、左が `J2`・レベルシフト・`C7`、上が MCU、右下が RJ45 / RS-485 / Buck / `J3`。`C7` と `U6` は `J2` の直上。`F1` / `D1` は `J1` から `J3` への短い 12 V 経路。`L1` は `J3` の内側がアンカー。

`U4`（`ESP32-C3-MINI-1-N4`）は USB と RJ45 のあいだ、上辺。**rot 0 でアンテナは上**。銅箔禁止帯は上辺 `y < 5.85`。前部のように横へ回さない。衝突判定はモジュール本体の箱を使い、アンテナのフルコートヤードは使わない。

既知の完成は **66 × 42 mm**、レシピ `sw_left_d1_down`（`U1` rot 0、`L1` rot 90、`D1` rot 90）。DRC 0、未接続 0。穴は `H2 (4.0, 9.0)`、`H1` は `J3` の上 `(58.2, 20.5)`。記録は `hardware/rear-core/out/best-recipe.txt`。探索スクリプトは `DEFER_MOUNTING_HOLES` で穴を後回しにする。完成基板から穴を消さない。縮小の順は 66×42、64×42、64×40。下辺のコネクタ順とアンテナ上向きを崩す配置探索は、頼まれずに走らせない。

Buck のレシピ探索では、スイッチピンが `L1` を向く置き方を優先する。完成レシピは `sw_left_d1_down` なので、別レシピへ勝手に差し替えない。
