# LEDtape — 重力バウンス積み重ねデモ

M5Stack Basic に接続した WS2812 LED テープ上で、白いボックスが重力で落下・バウンスし、積み重なるデモです。

## ハードウェア

| 項目 | 内容 |
|------|------|
| 本体 | M5Stack Basic（Core ESP32） |
| LED | WS2812 / WS2812B テープ **144 石** |
| 接続 | Grove **Port B**（データ = GPIO **26**） |

電源はテープ長・明るさに応じて外部 5V 供給を推奨します。GND は本体と共有してください。

## 機能

- **A**: 上端からボックス（3 ドット幅）を落下。加速 → 底でバウンス → 減衰して着地
- 着地済みボックスの上に積み重なる（最大 48 個 = 144 ÷ 3）
- **B**: 積み上がったボックスを下方向へ排出（テープ外へ消える）
- **C**: 表示色を **白一色 ⇔ ボックスごとランダム色** で切り替え

LCD に LED 数・ボックス数・カラーモードと操作説明を表示します。

## 操作

| ボタン | 動作 |
|--------|------|
| A | ドロップ（上から落とす） |
| B | 排出 |
| C | 白 / ランダム色の切り替え |

## 設定

`src/main.cpp` 先頭付近で調整できます。

| 定数 | 意味 | デフォルト |
|------|------|------------|
| `NUM_LEDS` | LED 個数 | `144` |
| `LED_PIN` | データピン | `26`（Port B） |
| `BOX_SIZE` | ボックス幅 | `3` |
| `BRIGHTNESS` | 明るさ | `40` |
| `GRAVITY` | 重力加速度 | `160` |
| `RESTITUTION` | 反発係数（小さいほど早く収束） | `0.68` |

## ビルド・書き込み

[PlatformIO](https://platformio.org/) 前提です。

```bash
cd Gray/LEDtape
pio run          # ビルド
pio run -t upload
pio device monitor
```

依存ライブラリ（`platformio.ini`）:

- `m5stack/M5Stack`
- `fastled/FastLED@3.6.0`（最新版は C++17 必須のため固定）
