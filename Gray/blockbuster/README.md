# blockbuster — ブロック崩し

M5Stack Basic / Gray 向けのクラシックなブレイクアウト（ブロック崩し）です。マルチボールやパドル拡大などのパワーアップ、ウェーブ進行、効果音付きです。

## ハードウェア

| 項目 | 内容 |
|------|------|
| 本体 | M5Stack Basic / Gray（Core ESP32） |
| 表示 | 本体 LCD（320×240） |
| 入力 | 本体ボタン A / B / C |
| 音声 | 本体スピーカー |

外部ユニットは不要です。

## 機能

- 10×6 のレンガを壊してスコアを稼ぐ
- ウェーブが進むほどボールが速くなり、パドルが短くなる
- 上位行は複数ヒットの硬レンガ（ウェーブ 2 以降）
- レンガ破壊時に約 28% でパワーアップが落下
- ライフ 3 から開始（最大 5）。ハイスコアはセッション内で保持
- スプライト二重バッファで描画、効果音あり

## 操作

| ボタン | 動作 |
|--------|------|
| A | パドル左へ |
| B | 開始 / ボール発射 / ゲームオーバー後にタイトルへ |
| C | パドル右へ |

タイトルで **B** → プレイ開始。ボールがパドル上に載っているときは **B** で発射します。

## パワーアップ

落下アイコンをパドルで受け止めると発動します。

| 表示 | 効果 | ボーナス |
|------|------|----------|
| **M**（マゼンタ） | マルチボール（最大 3） | +50 |
| **W**（シアン） | パドル拡大 | +20 |
| **L**（緑） | ライフ +1（上限 5） | +30 |

## スコア

- レンガ破壊: `10 + 行種 * 10`（上の行ほど高得点）
- 全消しで WAVE CLEAR → 次ウェーブへ自動進行

## ビルド・書き込み

[PlatformIO](https://platformio.org/) 前提です。

```bash
cd Gray/blockbuster
pio run          # ビルド
pio run -t upload
pio device monitor
```

シリアルが不安定な場合は `platformio.ini` の `upload_speed` を `115200` にしてください（既定値）。

依存ライブラリ（`platformio.ini`）:

- `m5stack/M5Stack`
