# Gray / mic — Unit MIC 実験メモ

M5Stack Gray に [Unit MIC (U096)](https://docs.m5stack.com/en/unit/mic) を接続し、リアルタイム波形取得と内蔵スピーカ再生を試みた記録です。

**結論（現状）:** このユニットでは「声らしい連続波形の録音→再生」には至っていない。得られる信号は音声波形というより、しきい値超えのインパルス／矩形に近い。

---

## ハードウェア

| 項目 | 内容 |
| --- | --- |
| 本体 | M5Stack Gray（クラシック ESP32 Core） |
| マイク | Unit MIC（MAX4466 アナログ + LM393 デジタル） |
| 想定ポート | PORT.B（黒） |
| 内蔵スピーカ | GPIO25 / 8bit DAC |

### Unit MIC ピン（HY2.0-4P）

| 線 | 役割 | Gray Port B |
| --- | --- | --- |
| 黒 | GND | GND |
| 赤 | 電源（公式 5V） | 5V または実験で 3.3V |
| 黄 | デジタル出力（コンパレータ） | G26 |
| 白 | アナログ出力（MAX4466） | G36（ADC） |

- 本体側にマイクは無い（Fire の内蔵マイクとは別物）。
- ポテンショは公式には **デジタルしきい値** 用（アナログゲインではない）。

## ビルド / 書き込み

```bash
cd Gray/mic
pio run -t upload
pio device monitor
```

- PlatformIO: `platformio.ini`（`m5stack-core-esp32` / `m5stack/M5Stack`）
- 現在の `src/main.cpp` は **信号分類診断**（波形アプリではない）
  - `min/max/mean`、`low%/mid%/high%`、ゼロクロス概算 `zc~Hz`
  - 判定文字列（`CLIP/RAIL` など）
  - **C** ボタン: 440 Hz 正弦波（内蔵スピーカ／DAC 動作確認）

## 当初の目的

1. Grove（のち直結）でマイク波形をリアルタイム取得できるか
2. 録音結果を内蔵スピーカから再生できるか

理論上は「アナログ ADC サンプリング → 8bit DAC 再生」で可能な構成。実装・配線・信号の性質の両面でつまずいた。

---

## うまくいかなかったこと / 切り分けログ

### 1. Grove 接続時は挿抜しても ADC が変わらない

- 初期は Port B 想定で `analogRead(36)` したが、ケーブル挿抜で値がほぼ同じ。
- **配線ミス**が判明。直結後は G36 の反応あり（抜くと別挙動）。

### 2. 高速サンプリングの「下りスロープ」は音声ではない

- 画面に緩い下り勾配＋微振動が出て、声に無反応に見えた時期あり。
- これはスペクトル表示ではなく時系列表示のつもりだったが、**浮きピン／高速連続 ADC の垂れ**に近いアーティファクトだった。
- G36 を抜くとスロープ、挿すと別信号 → ピン自体は生きていることの確認に使えた。

### 3. 録音再生は「ブリブリ」で声に聞こえない

- バッファ録音 → `dacWrite(25)` 再生を試したが、声としては認識できない。
- 途中、`M5.begin()` が GPIO25 に LEDC を掴む問題に気づき `M5.Speaker.end()` で DAC 用に切り離し。
- **C の正弦波**はスピーカ／DAC 経路の確認用（こちらはトーンとして出る）。

### 4. ずっと `CLIP/RAIL`（両端張り付き）

診断での典型値:

- `CLIP/RAIL`
- `low%≈50`, `mid%≈0`, `high%≈50`（ほぼ完全な矩形）
- 見た目・聴感とも **ブザー的**

解釈の経過:

| 仮説 | 結果 |
| --- | --- |
| 12bit を 16bit と勘違い？ | **否定**。ESP32 SAR ADC は 12bit（0..4095）。`CLIP/RAIL` は実測が両端を往復している |
| δ-σ（PDM）の δ を生で読んでいる？ | **否定**。Unit MIC はアナログ MAX4466。積分・CIC は不要な種類 |
| 黄線（デジタル）の混入？ | 黄を抜いても同様 → **アナログ経路側の問題** |
| 5V 駆動が 3.3V ADC を飽和？ | 有力候補だったが、**電源を 3.3V・白のみ**にしても `CLIP/RAIL` 継続 |

### 5. 「ゲイン」調整後: フラット + 声でインパルス列

- ツマミを調整するとほぼフラットになり、声をかけると **ばばばっとインパルス**が入る。
- 連続した音声波形（母音の周期など）には見えない。
- 実態は **音イベント／ピーク検知に近い**信号で、録音再生向きではない。

---

## 現状の判断

- Unit MIC（U096）は「音→電気」「サウンドスイッチ」用途としては説明と一致しうる。
- **音声波形の忠実な取得・内蔵スピーカでの再生**には不向き、または本セットアップでは未達。
- ソフトのバイアス除去や表示ズームでは、矩形／インパルスを声には戻せない。

## 代替案（未実装・検討メモ）

| 案 | 見込み | メモ |
| --- | --- | --- |
| Unit Mini PDM（SPM1423）+ I2S PDM | 波形用途では本命寄り | Port／ピン合わせが必要。Gray では Port A 例が多い |
| アナログは 5V のまま分圧して ADC | 飽和対策としては有効な場合あり | 今回は 3.3V 化でも矩形のままなので本丸ではなかった |
| 内蔵スピーカの DAC | 正弦波確認済み | 8bit・音質は限定的。再生経路自体は死んでいない |
